## これは何？

**分子って実際どんな形をしているの？電子はどう分布しているの？なぜこの結合は切れて、あの結合は切れないの？**

こうした疑問は、量子力学を使って原理的には計算できます——それが「量子化学」や「計算化学」のやっていることです。

でも従来の量子化学計算には、こんな手間がかかります：

- Linuxサーバーを用意してセットアップする
- コマンドラインでインプットファイルを書き方を覚える
- ジョブキューで長時間待つ
- 出力ファイルを手動でコピーしてグラフを自分で描く

この一連の作業はとっつきにくく、多くの学生が始める前に挫折してしまいます。

**ClearQCは、そのすべての障壁をなくすことを目指しています。**

計算したい分子の名前を入力するだけで——たとえば「カフェイン」や「benzene」——ボタンをクリックすると、数分後には以下の結果が表示されます：

- 分子の3D構造
- 全エネルギーと原子上の電荷分布
- フロンティア軌道（HOMO / LUMO）の可視化
- IRスペクトルやUV-Vis吸収スペクトル（対応する計算を選択した場合）

**すべてWindowsパソコン上でローカルに動作します。計算にネット接続は不要、アカウント不要、Pythonの知識も不要です。**

## 量子化学で何が計算できるの？

「量子化学」が抽象的に聞こえるなら、具体例で説明します：

**🔬 構造最適化（Geometry Optimization）**
おおまかな初期構造を与えると、コンピュータが最もエネルギーの低い安定な3D形状を探し出してくれます。引き伸ばしたバネが自然な平衡位置に戻るイメージです。

**⚡ フロンティア軌道（HOMO / LUMO）**
HOMOは「最高被占軌道」、LUMOは「最低空軌道」の略です。この2つの軌道が、反応で分子がどこで電子を与え、どこで受け取るか——つまり反応性——を決めています。ClearQCはこれらを美しい3Dの等値面として表示します。

**🌈 UV-Vis吸収スペクトル（TD-DFT）**
なぜベンゼンは紫外域で吸収があるの？なぜ色素には色があるの？励起状態計算（TD-DFT）で、分子がどの波長の光を吸収するか予測できます——実験室のUV-Vis分光光度計の結果と直接対応します。

**📳 赤外スペクトル（IR）**
化学結合はバネのように特定の周波数で振動します。振動数計算でIR吸収バンドの位置が予測でき——実験室のIRスペクトルと直接対応します。

**🧪 Mulliken電荷**
各原子が持つ過剰電荷がわかります。極性、水素結合サイト、求核・求電子部位の理解に役立ちます。

## システム要件

ClearQCは現在 **Windows 10 / 11（64ビット）のみ** 対応しています。

また、**WSL 2**（Windows Subsystem for Linux 2）を有効にする必要があります。WSL 2はWindowsに内蔵の機能で、WindowsでLinuxプログラムを動かすものです。ClearQCの計算エンジン（PySCF）はこのLinux環境上で動きます。**Linuxの知識は一切不要**です——ClearQCがすべて自動で処理します。

### WSL 2の有効化手順

1. PowerShellを**管理者として**開く（スタートメニューで「PowerShell」を検索 → 右クリック → 管理者として実行）
2. 以下のコマンドを入力してEnterを押す：
   ```
   wsl --install
   ```
3. インストール完了後、**PCを再起動**する

再起動後、WSL 2が使えるようになります。問題が発生した場合は[Microsoftの公式ドキュメント](https://learn.microsoft.com/ja-jp/windows/wsl/install)を参照してください。

### ハードウェア推奨環境

| | 最低 | 推奨 |
|--|------|------|
| メモリ | 4 GB | 8 GB以上 |
| ディスク空き容量 | 600 MB | 1 GB以上（計算の一時ファイル含む） |
| CPU | x64であれば可 | コア数が多いほど高速 |

## ダウンロードとインストール

[Releasesページ](https://github.com/SigmaAdrich/ClearQC/releases/latest)から最新版をダウンロードしてください。

2種類のインストーラーがあります：

**📦 オフラインインストーラー（初めての方に推奨）**
ファイル名に`offline`が含まれます、約135 MB。計算エンジンが同梱されており、ダウンロードしてダブルクリックするだけで完了。**ネット接続不要。**

**📦 オンラインインストーラー（通信環境が良い場合）**
ファイル名に`online`が含まれます、約14 MB。インストーラー自体は小さいですが、**初回起動時に約120 MBの計算エンジンをダウンロード**します（ネット接続が必要）。以降は不要。

> **どちらを選べばよいか迷ったら？** オフラインインストーラーを選んでください——必ず動作します。

### インストール手順

1. `.exe`インストーラーをダウンロード
2. ダブルクリックして実行。Windowsがセキュリティ警告（「PCが保護されました」）を表示することがあります。その場合は **詳細情報 → 実行** をクリックしてください
3. インストールウィザードの指示に従って進める
4. スタートメニューまたはデスクトップのショートカットから **ClearQC** を起動
5. **初回起動時**、アプリが自動でWSL計算環境をインポートします——30〜60秒かかります。ウィンドウを閉じずお待ちください
6. メイン画面が表示されたら、準備完了です！

## 5分クイックスタート

**ステップ1：分子名を入力**

左側のチャット入力欄に `/compute caffeine` と入力してEnterを押します。

アプリが内蔵の分子ライブラリからカフェインを検索し、チャットパネルに**計算カード**が表示されます。

**ステップ2：計算パラメータを設定**

カードにはすでに推奨設定（B3LYP / def2-SVP——速度と精度のバランスが良い）が選択されています。**Adjust**ボタンをクリックするとさらに詳細を調整できます：

- **手法（Method）**：HF（速いが精度は低め）またはB3LYP（推奨のDFT法）
- **精度（Precision）**：Fast / Balanced / Accurate
- **タスク（Task）**：一点エネルギー（SP）/ 構造最適化（Opt）/ 振動数（Freq）/ 励起状態
- **溶媒**：溶液中の計算をシミュレートしたい場合に選択

初めての場合はデフォルトのままでOKです。

**ステップ3：Computeをクリック**

緑色の **Compute** ボタンをクリックします。右側のステータスバーに計算の進捗が表示されます。

カフェインのような小分子はBalanced精度で約1〜3分かかります。

**ステップ4：結果を確認**

計算が完了すると結果カードが表示されます：

- 全エネルギー（Hartree単位）
- 収束状態
- Mulliken原子電荷
- 計算時間

右側のパネルには3D構造が同時に表示されます。ドロップダウンメニューで **HOMO、LUMO、電子密度**の等値面を切り替えて確認できます。

**ステップ5（任意）：AIに解説してもらう**

結果カードの下部に **AI Explain** ボタンがあります。AIエンドポイントを設定済みであれば（設定 → AI設定）、クリックすると計算結果のわかりやすい解説が生成されます。

## よくある質問

**Q：アプリが起動しない、またはWSLが見つからないと表示される？**
A：上記の手順でWSL 2を有効化し、PCを再起動してから再試行してください。

**Q：初回起動時に「計算環境をインポート中」で長時間止まっている？**
A：これは正常です——WSLのインポートはディスク速度によって30〜60秒以上かかることがあります。ウィンドウを閉じずにお待ちください。

**Q：計算がエラーで失敗する？**
A：最もよくある原因は電荷やスピンの設定ミスです（例：陽イオンを計算するのに電荷を+1に設定し忘れた）。結果カードの **AI Diagnose** ボタンで自動診断を試してみてください。

**Q：どのファイル形式に対応していますか？**
A：XYZ、PDB、MOL/SDF、Gaussian GJF/COMファイルをウィンドウに直接ドラッグ＆ドロップできます。

**Q：計算がとても遅い？**
A：量子化学計算はもともと計算負荷が高いです。分子が大きく、基底関数系が大きく、タスクが複雑なほど時間がかかります。まずはBalanced精度で一点エネルギー（SP）から試してみてください。

**Q：MacやLinuxでは使えますか？**
A：現時点ではWindows 10/11のみ対応しています。Mac/Linux版は予定していません。
